# CivicPulse AI Hub — Wanadongri, Nagpur

An offline-first smart village community intelligence platform built for Wanadongri (Hingna Road, Nagpur, Maharashtra).

## Modules Included
- **Wanadongri Resource Map (GIS):** Offline vector map of local water tanks, RO ATMs, check dams, health centres, schools, and solar microgrids.
- **Rural Health Triage & BMI Screening:** Offline symptom triage and Asian-Indian WHO/ICMR BMI & nutrition screening.
- **Dialect AI STEM Tutor:** Zero-data Marathi/Hindi/English lessons with interactive quizzes.
- **LoRaWAN Climate & Farmer Assistance:** Soil telemetry, drip irrigation alerts, and Vidarbha crop guidance.
- **Citizen Complaints & Admin Dashboard:** Local issue reporting, status tracking, and CSV export.
- **Government Schemes, Weather/AQI & Emergency Directory:** Quick access to official portals and emergency contacts (112 / 108).
- **Encrypted SQLite Mesh Sync Queue:** Local offline packet storage with simulated cloud uplink sync.
